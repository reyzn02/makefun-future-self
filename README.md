A program that writes a single funny text from your future self — one
message, under 200 characters, that lands with no setup at all — and
saves it as `entry.txt` for the judges.

## How to run

```sh
$ python3 main.py
```

The text lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default).
